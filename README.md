# Marketplace Multivendedor
PATRONES DE SOFTWARE  - GRUPO A194
El proyecto consiste en desarrollar un Marketplace Multivendedor, una plataforma digital donde diferentes vendedores pueden ofrecer y administrar sus productos desde un mismo sistema. Los clientes podrán consultar el catálogo, realizar pedidos y pagos, calificar sus compras y recibir recomendaciones de productos según sus intereses.
